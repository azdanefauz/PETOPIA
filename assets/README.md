# Asset Folder Guide for Petopia 🎨

Folder ini dibuat agar tim desain dapat mengupload dan mengedit aset langsung di GitHub!

### Struktur Folder:
- **`fonts/`**: Taruh custom font `.ttf` atau `.otf` di sini (nama file: `game_font.ttf`).
- **`images/logo/`**: Logo utama Petopia (`logo.png`, rekomendasi resolusi ~300x180).
- **`images/pets/`**:
  - `cat.png`: Sprite / spritesheet kucing
  - `dog.png`: Sprite / spritesheet anjing
  - `rabbit.png`: Sprite / spritesheet kelinci
  - `nanda.png`: Sprite / spritesheet nanda
  - `pet_illustration.png`: Ilustrasi besar di menu penamaan pet
- **`images/backgrounds/`**:
  - `livingroom.png`: Background ruang tamu (760x350)
  - `kitchen.png`: Background dapur (760x420)
  - `backyard.png`: Background halaman belakang (760x420)
  - `bedroom.png`: Background kamar tidur (760x420)
- **`images/ui/`**: Tombol dan icon custom
